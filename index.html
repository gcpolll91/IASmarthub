¿Cómo obtener tu API Key Gratis?

  1. Inicia sesión en Google AI Studio .
  2. Haz clic en el botón "Get API Key" arriba a la izquierda.
  3. Crea una nueva clave API para un proyecto existente o nuevo.
  4. Copia el código generado (comienza usualmente con AIzaSy...) y pégalo abajo.
